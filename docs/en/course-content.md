# English Course Content Entry

This document describes how the English content in this repository is organized.

Conventions:

- Course-level documents live under `docs/`
- Module code and module-specific assets live under `modules/`
- English module tutorials live under `docs/en/`, following the same `mXX-xxx/` numbering as `modules/`
- The English homepage is `README.md` at the repository root

Recommended starting points:

- `README.md`
- `docs/syllabus.md`
- `docs/module-map.md`
- `modules/`
