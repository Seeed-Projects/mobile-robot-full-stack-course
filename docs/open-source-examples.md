# Open-Source Examples

This repository structure was informed by patterns seen in these public projects:

## Repositories

- `Seeed-Projects/AI_Robotics_Academy`
  - <https://github.com/Seeed-Projects/AI_Robotics_Academy>
  - Useful for: hardware-oriented AI robotics education packaging
- `henki-robotics/robotics_essentials_ros2`
  - <https://github.com/henki-robotics/robotics_essentials_ros2>
  - Useful for: course-oriented ROS 2 learning progression and examples
- `ros2/ros2_documentation`
  - <https://github.com/ros2/ros2_documentation>
  - Useful for: docs-first structure and long-term contributor friendliness
- `NVIDIA-ISAAC-ROS/isaac_ros_common`
  - <https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_common>
  - Useful for: containerized robotics workflows and Jetson-oriented development conventions

## Takeaways Applied Here

- Keep documentation navigable from the root.
- Separate course content from implementation assets.
- Make hardware and deployment first-class parts of the repository.
- Treat capstone projects as integration surfaces, not isolated folders.
