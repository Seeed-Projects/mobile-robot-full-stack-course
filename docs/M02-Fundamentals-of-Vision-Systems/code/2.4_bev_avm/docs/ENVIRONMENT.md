## Deviations from the master spec

- Spec assumes **AGX Orin 64GB**; this device is the **32GB** SKU (8 CPUs, 29 GB RAM
  usable). All performance targets are kept; memory budget for the engine +
  runtime (~4–6 GB workspace) is still comfortable.
- Only **~10 GB free** on the root partition: nuScenes-mini and build trees fit,
  but cleanup discipline is required (see `scripts/collect_diagnostics.sh` and
  `build_workspace.sh` notes).

## Environment-modification policy

Any required change (e.g. apt installs, power-mode switch) must be: justified
here → impact listed → rollback documented. None required so far; all needed
toolchain components were present on the stock Seeed JetPack 6.2.1 image.
