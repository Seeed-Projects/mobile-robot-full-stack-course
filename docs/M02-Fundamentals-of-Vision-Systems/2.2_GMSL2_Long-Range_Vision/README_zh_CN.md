# 2.2 GMSL2 长距离视觉：车载级多相机接入

## 课程目标

掌握 J501 的 GMSL2 扩展能力，实现多路高带宽相机同步采集。

## 硬件清单

- J501 + GMSL 扩展板
- Sensing SG2-IMX390 / SG8S-AR0820 GMSL2 相机
- Fakra 线缆

## 前置基础

- M1.1（硬件接口）
- M2.1（CSI 基础）

## 理论要点

- GMSL2 协议：同轴供电（PoC）+ 数据 + 控制，最长 15m。
- MAX96712 解串器配置：4×4 模式与链路锁定（Link Lock）诊断。
- 多相机同步：外部触发（FSYNC）与 PTP 时间戳对齐。

## 实践内容

- 连接 2–4 路 GMSL2 相机，验证 V4L2 枚举。
- 配置 MAX96712 的 I2C 地址与链路参数。
- 使用 `nvsipl` 或自定义 V4L2 驱动实现 4 路 1080p 同步采集。
