# 2.4 相机标定：内外参与联合标定

## 课程目标

完成单目/双目标定，建立像素到物理空间的映射。

## 硬件清单

- J501
- 1–2 路相机
- 标定板（棋盘格 / ChArUco）

## 前置基础

M2.1–M2.3（相机正常工作）。

## 理论要点

- 相机模型：Pinhole + 畸变系数（k1, k2, p1, p2, k3）。
- 手眼标定基础：Eye-in-hand vs Eye-to-hand（为 M9 机械臂预铺垫）。
- 双目标定与极线校正（Rectification）。

## 实践内容

- 使用 `camera_calibration` 或 Kalibr 进行单目/双目标定。
- 计算重投影误差，评估标定精度。
- 保存 `camera_info` YAML 供后续 SLAM/检测模块调用。

## 产出物

标定参数 YAML 文件 + 标定精度报告。
