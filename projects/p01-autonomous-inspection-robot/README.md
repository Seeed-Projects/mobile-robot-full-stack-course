# P1: Autonomous Inspection Robot

## Goal

Build a robot that patrols a route, detects anomalies, and reports findings.

## Recommended Prerequisites

- M4
- M6
- M8

## Expected Stack

- Mobile base
- Multi-camera or PTZ vision
- LiDAR-based mapping and navigation
- Detection and reporting pipeline

## Outputs

- inspection route demo
- anomaly evidence capture
- structured inspection report
