# M3: LiDAR and Sensor Fusion

## Focus

Integrate LiDAR, IMU, GNSS, and CAN-FD into a synchronized perception backbone.

## Topics

- LiDAR drivers and point cloud preprocessing
- IMU, GPS, and CAN-FD integration
- Time synchronization and spatial alignment
- EKF-based state estimation

## Deliverable

A synchronized multi-sensor pipeline ready for SLAM and navigation.
